# Fireflies Restaurant & Bar — Digital Menu (जुनेकिरी)

> **जुनेकिरी — Light in the Dark** • *Flavors and Fizz*  
> Official QR-code mobile-first digital menu website for **Fireflies Restaurant & Bar**, Kathmandu, Nepal.

---

## Overview

A high-performance digital menu website designed for seamless table-side QR code scanning. Built with **React 19**, **Vite 8**, and **Tailwind CSS v4**, this digital menu features 100% verified menu coverage across all **125 items (68 Food Items + 57 Beverages & Bar SKUs)**.

### Key Features
- **Mobile-First Luxury Experience:** Dark-themed ambiance tailored for evening restaurant lighting.
- **Instant Search & Dynamic Filtering:** Instantaneous zero-latency search by item name, ingredients, or preparation notes.
- **100% Verified Menu Accuracy:** All prices, portion sizes, and variants are audited against physical restaurant documents.
- **Thakali Khana Notices:** Preserves mandatory kitchen guidelines (*Minimum 4 Packs Order & Wait time 30-50 mins*).
- **Hard Drinks Bottle Matrix:** Clear pricing for Whiskey, Vodka, Rum, and Gin across Quarter (~180ml), Half (~375ml), and Full Bottle (~750ml).
- **Pizza Customizer:** Comparison layout for 12" Medium and 18" Party Size pizzas, plus the Do It Yourself customizer.
- **Direct Table Service & Delivery:** Built-in hotline connectivity to `9841960700`.
